# Задание Codex: встроить готовый TAIL Backend V1

У меня есть ZIP с настоящим Node.js backend `TAIL_BACKEND_V1`. Это НЕ генерация текста: исходники уже написаны, есть восемь проходящих локальных тестов и отдельно проверен HTTP smoke test.

1. Распакуй архив рядом с существующим проектом TAIL.
2. Сначала изучи backend из ZIP и текущий код TAIL. Сопоставь endpoints и data types.
3. Запусти `npm test`, затем `npm start` и `npm run smoke` для нового backend. Не изменяй production.
4. Поэтапно подключи search, token details, GeckoTerminal OHLCV, stream fallback, wallet balances, Jupiter quote, Fable.
5. Не меняй визуал, CSS, верстку, маскота или анимации.
6. Используй адаптеры, сохрани обратную совместимость с текущими API.
7. Если отсутствуют `.env` секреты, не подставляй фиктивные ключи. Сообщи, что именно нужно настроить локально.
8. Функции buy/sell execution, PnL, 24/7 alerts и полный social monitor в этом backend НЕ реализованы. Не объявляй их готовыми и не добавляй незащищённую отправку транзакций.
9. Для каждого модуля составь реальные тесты. Проверяй со сторонними API только безопасные GET/read-only вызовы.
10. В конце предоставь список подключённых endpoints, screenshots UI при необходимости, тестовый отчет и список оставшихся задач. Без автоматического деплоя.
