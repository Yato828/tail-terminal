# TAIL Backend V1 — запускаемая основа

Это **настоящий backend-сервер**, а не мокап, не промт и не коллекция декоративных кнопок. Он запускается без `npm install`, отдаёт HTTP JSON API, принимает реальные ответы внешних сервисов при наличии доступа к Интернету, и включает локальные интеграционные тесты с контролируемыми ответами провайдеров.

**Принципиальные ограничения:** это standalone-код, **не** патч текущего репозитория TAIL; браузерные UI и production сервера он автоматически не заменяет. Торговое исполнение (подпись/отправка buy/sell) намеренно отключено до независимого аудита транзакций, чтобы не повторить проблему предыдущего backend. Настоящие внешние ответы Solana и OpenAI в этой среде не прогонялись.

## Быстрый запуск (macOS / Linux / Windows c Node.js 22+)

```bash
cd TAIL_BACKEND_V1
cp .env.example .env
npm start
```

Проверка в другом терминале:

```bash
curl http://127.0.0.1:8787/api/health
curl 'http://127.0.0.1:8787/api/market/search?q=solana'
curl 'http://127.0.0.1:8787/api/market/profiles?limit=10'
```

Тесты:

```bash
npm test
npm run smoke  # когда сервер уже запущен
```

**API использует Node.js без сторонних npm-зависимостей.** Требуется Node.js 22+. Секреты хранятся только в `.env` (его нельзя публиковать). JSON watchlists/alerts хранятся в `data/`.

## Что реализовано

| Система | Статус | Как работает |
|---|---|---|
| Health/capabilities | Работает | Готовность конфигурации, явно показывает что торговля выключена |
| Token search | Код готов | Поиск и нормализация пар DexScreener |
| Token details | Код готов | Все рынки и лучшая пара по ликвидности |
| Filters | Код готов | Liquidity, market cap, volume, 5m buys, age, DEX. Только поля, которые источник действительно отдаёт |
| Recent token profiles | Код готов | Последние индексированные профили DexScreener, **не** полный поток запусков |
| Boosted tokens | Код готов | DexScreener boosts, **не** рейтинг органического спроса |
| New pools | Код готов | GeckoTerminal indexed new pools |
| Historical OHLCV | Код готов | GeckoTerminal, 1m/5m/15m/1h/4h/12h/1d |
| Historical trades | Код готов | Пул GeckoTerminal, до 100 доступных сделок |
| Market stream | Работает как polling SSE | Общая подписка на токен, опрос DexScreener каждые 10 секунд, **не tick WebSocket** |
| Solana wallet balances | Код готов | `getBalance`, `getTokenAccountsByOwner` для SPL Token и Token-2022 |
| Wallet activity | Код готов | Solana signatures, **не** классификация buy/sell |
| Transaction status | Код готов | RPC `getSignatureStatuses` |
| Jupiter quote | Код готов | Swap API V2 `/order` без `taker`, только цены и комиссии, **без** подписываемой транзакции |
| Watchlist | Работает локально | Анонимная bearer-сессия и JSON persistence |
| Alerts | Работает условно | Пороговые однократные события, только пока активен поток токена |
| Fable 5.2 | Требует ключ и модель | Настоящий OpenAI Responses API с чтением Solana market/wallet tools, до 4 tool calls |
| Реальные buy/sell | **НЕ реализованы** | Без безопасного валидатора, подписания и журнала отправки сделок включать нельзя |
| PnL/positions | **НЕ реализованы** | Баланс и отдельные подписи не дают достоверную себестоимость |
| Полный X/TG social radar | **НЕ реализован** | Нужны разрешённые API и лимиты |
| Собственный Pump.fun indexer | **НЕ реализован** | Индексированные рынки могут запаздывать |

## Fable 5.2

1. Получи API-ключ OpenAI и укажи `OPENAI_API_KEY`. По умолчанию используется `OPENAI_MODEL=chat-latest` — GPT-модель ChatGPT через OpenAI API. В интерфейсе и ответах имя ассистента остаётся **Fable 5.2**. При необходимости `OPENAI_MODEL` можно явно переопределить доступной аккаунту моделью.
2. Проверь `GET /api/fable/status`.
3. Вызови `POST /api/fable/chat` с `{"message":"Analyze this token","context":{"mint":"..."}}`.

Без `OPENAI_API_KEY` Fable 5.2 честно возвращает 503 и НЕ генерирует фальшивых AI-ответов. Есть базовый IP rate limiting и дневной лимит 100 запросов на процесс; **это не гарантированный денежный лимит** в распределённом production. Реальные API-вызовы OpenAI тарифицируются отдельно и не входят в «бесплатную инфраструктуру».

Fable — **название ассистента внутри TAIL**, а не утверждение, что мы обучили самостоятельную модель. Модельный провайдер должен быть указан в информации о продукте.

## Безопасность и эксплуатация

- Нет приватных ключей пользователя. Нет seed, нет отправки транзакций, нет write RPC прокси.
- В Jupiter `/order` не передаётся `taker`; поля `transaction` и `requestId` не попадают в JSON-ответ.
- Имена, адреса и суммы валидируются. URL к провайдерам фиксированы, нельзя передать произвольный host.
- Есть ограничения размера body, upstream-ответа, времени запроса, rate limits и ограничение на количество потоков.
- Разрешённые CORS origins задаются в `.env` — **укажи реальный домен TAIL**.
- Anonymous bearer session **не** является SIWS-аутентификацией, доказательством владения кошельком или системой для хранения секретов. Не привязывать к ней реальные позиции/деньги.
- Локальный JSON storage рассчитан на **один процесс**. Для публичной многопроцессной системы нужна БД и настоящая авторизация.
- Фоновые алерты **не** работают 24/7: они вычисляются лишь для токенов с активной SSE-подпиской.
- Dev defaults: сервер слушает `127.0.0.1`; прежде чем включать в Интернет, нужны HTTPS/reverse proxy, persistent rate limits, monitoring, hard quotas, auth и security review.
- Тесты проверяли локальное поведение с заглушёнными ответами внешних API. Это **не доказательство** стабильной работы каждого стороннего API в production.

## Подключение к существующему TAIL

Читайте `docs/INTEGRATION_WITH_OLD_TAIL.md`. Есть пример React API-adapter: `examples/frontend-adapter.js`.

Основная цель первого релиза — оставить старый frontend и backend неизменными, протестировать standalone API локально и интегрировать по одному модулю. Полный rewrite или замена production запрещены.
