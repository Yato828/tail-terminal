## Исправленные функциональные проблемы

1. Trending сортировал объём за 24h при выборе другого timeframe. Сортировка и подпись объёма теперь используют 5m/1h/24h. Gainers включает известные положительные изменения выбранного периода.
2. Общий error-state Market Pulse и New Pairs позволял успешному обновлению одного источника скрывать ошибку другого. Состояния разделены; New Pairs обновляется раз в минуту во время просмотра.
3. Часовая история USDC не загружалась из выбранного по умолчанию PancakeSwap-пула: DexPaprika вернул 404. Добавлен ограниченный поиск покрытия среди максимум трёх других пулов **того же mint**. После проверки истории меняется сам выбранный рынок, а не только массив свечей. Новый pool ID виден в сообщении и URL, сохраняется после reload; источник live spot переключается вместе с рынком. История другого пула не выдаётся за историю первоначального.
4. Подключены реальные buys/sells за 24h в token info. Единственное дополнение backend этого этапа — совместимые необязательные поля `buys24h` / `sells24h`; неизвестные значения остаются null.
5. V1 больше не показывает применённый 1% slippage: выбран явный `Not applied · quote only`. Комиссия названа Provider fee. Исполнение Sell/Buy остаётся отключённым в V1.
6. В прежнем исполняемом адаптере истёкшую котировку можно обновить действием Refresh quote без включения wallet execution. Удалена бессмысленная внешняя ссылка SOL→SOL.
7. Bubble Map сохраняет обе причины недоступности — holder source и trader fallback. После ошибки больше нет ложного вечного сообщения Loading real wallet data.
8. В Portfolio явно обозначено отсутствие positions, cost basis и PnL. Реальные публичные балансы и история доступны отдельно.
9. Маскот связан с фактической загрузкой свечей, поиском, анализом, ответами/ошибками Fable и новыми alert events. Завершение фонового графика не объявляет успех ещё работающего AI-запроса.
