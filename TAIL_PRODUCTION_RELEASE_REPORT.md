## Оформление и персонаж

Большая оранжевая звезда восстановлена в точности: SVG, цвета, блики, следы и подпись совпадают с утверждённым вариантом. Изменён персонаж над ней: диагональная поза, асимметричные руки, подогнутые ноги и отдельное плавное движение. Силуэт собирается из исходных PNG через режим `presentation="floating"`; готовый runtime управляет дыханием, взглядом и переходами. Персонаж не перерисован. Размер canvas ограничен 320 CSS px.

У персонажей разные роли: главная — полёт над оранжевой звездой; блок расширения — отдельный статичный кадр сна из предоставленного runtime; вход — приветствие и загрузка; выход — потягивание; персонаж терминала — спокойное ожидание с реакциями на реальные события. Повторяющиеся декоративные canvas из preview и Info убраны. Приоритеты TailEventBridge и реакции на повторные клики сохранены.

Добавлена единая изогнутая четырёхлучевая звезда бренда. Главная использует крупную типографику, редакционные строки возможностей и действующий терминал внутри страницы. Оранжево-чёрная палитра сохранена. Reduced motion отключает полёт; встроенные переходы учитывают загрузку терминала, восстанавливают фокус и поддерживают Назад/Вперёд.

## Ограничения и ещё не подключённые функции

- **Fable 5.2:** серверный AI-сервис не настроен. Чат показывает недоступность и не выдаёт заготовленные ответы за результат модели. Оплачиваемые AI-запросы не выполнялись.
- **Торговля:** в опубликованной standalone-сборке есть котировки; подписание, buy/sell execution и автоторговля отключены. Реальных транзакций при проверке не было.
- **Покрытие Bubble Map:** USDC не имеет снимка в доступном индексаторе; публичные RPC ограничивают `getTokenLargestAccounts`. Для этой комбинации показывается ошибка источников, без вымышленных узлов. JUP с настоящим снимком проверен отдельно.
- **Лента сделок и связи кошельков:** зависят от покрытия индексатора. GeckoTerminal в проверенной среде ограничивал доступ; полной истории переводов, PnL ledger и автоматического рейтинга smart money нет.
- **Live pool spot:** доступен только при подтверждённом декодере поддерживаемого пула и рабочем PubSub. В остальных случаях сохраняется режим source candles. Token-wide свечи не смешиваются с pool spot; объём из изменения цены не создаётся.
- **Социальные и creative-инструменты:** ручной анализ и локальные SPL-черновики/экспорт не означают подключённые соцсети или публикацию токенов/сайтов. Live deployment этих инструментов отключён. Telegram, Pump.fun и X в хедере остаются явно отключёнными заглушками.
- **Уведомления:** нет фоновой доставки, серверной синхронизации локальных списков или доказательства владения кошельком через browser storage.
- **Расширение:** ZIP устанавливается через Load unpacked по инструкции на сайте; листинг Chrome Web Store не создавался.
