# TAIL — motion rig 04

16 ноября 2026, Europe/Minsk. Demo: http://localhost:4664/mascot.

## Персонаж и runtime

Использован утверждённый образ из supplied idle / state sheet: чёрный капюшон, кремовая окантовка, оранжевый знак и подкладка, тёмное лицо, светлые овальные глаза, ровно две ноги. Контуры SVG откалиброваны по утверждённому idle; среди состояний остаётся одна и та же геометрия персонажа.

`src/mascot/assets/tail-mascot.svg` содержит 34 именованных части. `src/mascot/animations.js` — новый непрерывный runtime v4. PNG/WebP, sprite frames и замена изображений не используются. Растровый оригинал на demo-странице — отдельный справочный образец справа.

У суставов сохраняются текущая позиция и скорость. Аналитически интегрируемая critically damped spring переводит их к новой цели; прерывание не начинает движение заново из idle. Положение головы, корпуса, рукавов, кистей, плаща и складки капюшона управляется отдельно. Голову и корпус движок не масштабирует. Scale применяется только к морганию глаз.

Idle содержит дыхание, моргание, небольшие движения рук/ткани и взгляд к указателю. В typing руки движутся независимо и обращены к рабочей зоне. Пропсы мысли, сканирования, графиков, ноутбука, предупреждения и сна — самостоятельные векторные слои с плавным появлением. Они не являются источником рыночных данных.

## Состояния и переходы

Реализованы: **idle, welcome, thinking, analyzing, searching, typing, success, warning, error, sleep, wake**.

На demo есть отдельная кнопка для каждого из 13 требуемых переходов:

- Idle → Thinking; Thinking → Analyzing; Analyzing → Success; Success → Idle.
- Idle → Searching; Searching → Idle.
- Idle → Warning; Warning → Idle.
- Idle → Error; Error → Idle.
- Idle → Sleep; Sleep → Wake; Wake → Idle.

Есть также объединённые цепочки, проверка приоритетов, Reset/stop и reduced motion. Preview закреплён при прокрутке, поэтому выбор находящихся ниже кнопок не выключает находящегося за экраном персонажа.

## Привязка к интерфейсу

| Событие | Состояние |
| --- | --- |
| Первое открытие терминала за сессию | welcome |
| Ожидание | idle |
| Ввод поискового запроса | searching до завершения запроса |
| Выбор токена / реальная загрузка свечей | analyzing |
| Обычный запрос к Fable | thinking |
| Действие Analyze token | analyzing |
| Успешный ответ / завершение собственной операции | success с последующим idle |
| Ошибка запроса/источника | error |
| Новый настоящий alert event | warning |
| Ввод сообщения | typing, если более приоритетная операция не выполняется |
| 90 секунд бездействия при отсутствии активной операции | sleep |
| Возвращение пользователя | wake → idle |

Приоритеты и владение операциями находятся в `state-machine/controller.ts`. Warning/error сохраняют приоритет над вводом и завершением поиска. Окончание фоновой загрузки не завершает анимацию незаконченного foreground AI-запроса. Клиент не выдумывает server tool-progress: V1 возвращает финальный JSON; stream tool events не реализованы.

## Доступность и проверка

- `prefers-reduced-motion` и настройка пользователя отключают циклическое движение и оставляют читаемую позу.
- В скрытой вкладке и вне viewport RAF останавливается; после возвращения нет накопленного прыжка времени.
- Каждый экземпляр получает собственные SVG IDs. React не пересоздаёт rig subtree на каждом состоянии.
- Unit-проверки: конечность и границы всех каналов, отсутствие scale тела/головы, сохранение позиции/скорости при прерывании, одинаковое поведение spring при 30/144 шагах, анатомия, reduced motion и приоритеты конкурирующих операций.
- Browser-проверки: тот же SVG и те же части через смены состояний, движение суставов, reduced motion, скрытая вкладка, отсутствие `NaN`/scale на теле и голове.
- Настоящий capture прошёл все **11 состояний и 13 переходов**. Во всех состояниях: 34 части и **0 SVG image elements**; все целевые состояния переходов наблюдались, ошибок JavaScript нет. Измерение фактического FPS не выполнялось.
