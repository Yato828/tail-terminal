# Интеграция TAIL 2D

Готовая система из `TAIL_2D_CODEX.zip` подключена вместо прежнего SVG-движка. Рабочая ветка: `codex/tail-2d-runtime-20261117`. Production не изменялся.

## Что используется

Все PNG и `motion-core.mjs` совпадают с пакетом побайтно. В `renderer.mjs` исправлен семплинг, создававший полосы на плаще и глазах. Новые позы, персонаж и анимационные кривые не создавались. Открыты и сверены предоставленные OPEN_DEMO, character sheet и SHOWCASE.

Интерактивный персонаж в Fable имеет размер **128 × 128 px** и работает через Canvas-runtime, а не переключение превью. Маленький логотип, favicon и справка используют предоставленный poster. React-компонент и `TailEventBridge` взяты из пакета. В обёртку добавлены подключение событий приложения, адаптация размеров существующих мест и наблюдаемый статус загрузки. Смена Reduce motion обновляет актёра без замены canvas. В runtime добавлены переключатель этого режима, проверка первоначально скрытой вкладки и закрытие ImageBitmap при отказе Canvas 2D; рисунок, приоритеты и motion-core сохранены.

Дизайн панелей, backend, API, запросы котировок, разрешения кошелька и торговая логика сохранены. По последней просьбе пользователя переходы увеличены примерно до 2,2 секунды и смягчены; завершение по-прежнему требует готовности настоящего интерфейса. Проценты загрузки не выдумываются.

## Реальные события

| Операция | Подключение |
| --- | --- |
| Поиск и открытие прямой ссылки | Уникальный requestId; searching до ответа, idle после результата, error при отказе, cancel при замене/размонтировании |
| Данные выбранного токена и графика | Отдельные задачи analyzing на время фактического чтения; завершение другой задачи не отменяет текущую |
| Fable | typing при вводе, thinking при запросе, success после ответа, error при отказе, cancel при Stop/размонтировании |
| Загрузка терминала | loading на реальную загрузку маршрута, welcome после commit готового интерфейса; неопределённый прогресс |
| Настройки, предупреждения, транзакции | Сохранение и предупреждения через bridge; подтверждение транзакции только из существующего подтверждённого результата |

Backend V1 возвращает обычный JSON и не передаёт потоковое событие tool-start. Оно не выдумывается: Fable остаётся thinking до ответа. Нативный обработчик `fable:tool:start` сохранён в мосте для транспорта, который действительно предоставляет такое событие. Анализ графика подключён к реальному чтению данных.

## Исправление качества и движения

Полосы происходили от отдельных дробных рядов плаща и столбцов глаз на конечном canvas. Теперь они собираются на целой пиксельной сетке и затем переносятся единым слоем; формулы движений и PNG сохранены. Добавлено сглаживание высокого качества и поддержка DPR до 3. В проверке равномерной полупрозрачной текстуры контраст стыков уменьшился с 0–48 уровней alpha до 0 во всех восьми комбинациях размера и DPR. Промежуточные поверхности освобождаются при destroy.

Удалена точка после «instinct». Звёздочка Home проходит по существующей орбите при наведении или фокусе и возвращается по той же траектории; Reduce motion отключает движение. Переходы получили более плавное раскрытие маски; в записи вход и возврат заняли примерно 2,6 с каждый с учётом взаимодействия и захвата кадров.

Проверены Chrome и WebKit: отсутствие швов, hover/возврат, reduced motion, browser Back/Forward, StrictMode и освобождение поверхностей. Существующие сценарии сайта и маскота сохранены. TypeScript, 148 unit-тестов и 15 тестов готового motion-core прошли. Fable и торговые вызовы при этой проверке не изменялись.
